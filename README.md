# 💳 سیستم مدیریت چک

یک سیستم کامل برای مدیریت چک‌های دریافتی و پرداختی با قابلیت یادآوری تلگرام.

## ✨ امکانات

- ✅ ثبت چک (دریافتی/پرداختی)
- ✅ تاریخ سررسید و یادآور
- ✅ جستجو و فیلتر پیشرفته
- ✅ تغییر وضعیت چک
- ✅ داشبورد آماری
- ✅ بات تلگرام اختصاصی
- ✅ طراحی ریسپانسیو
- ✅ دیتابیس SQLite

## 🚀 نصب و راه‌اندازی

### ۱. کلون کردن پروژه
```bash
git clone https://github.com/moha100h/check-manager-system.git
cd check-manager-system
```

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. ساخت توکن تلگرام
1. به @BotFather در تلگرام برو
2. /newbot بزن
3. یه نام و یوزرنیم بده
4. توکن رو کپی کن

### ۴. تنظیم متغیرها
```bash
cp .env.example .env
nano .env
# توکن رو وارد کن
```

### ۵. اجرای سرور وب
```bash
npm start
```

### ۶. اجرای بات تلگرام (در ترمینال دیگه)
```bash
npm run bot
```

## 📱 دسترسی

- وب: `http://localhost:3000`
- تلگرام: بات رو استارت کن

## 📂 ساختار فایل‌ها

```
check-manager-system/
├── server.js      # سرور اصلی
├── bot.js         # بات تلگرام
├── checks.db      # دیتابیس (بعد از اجرا ساخته میشه)
├── public/
│   └── index.html # فرانت‌اند
├── package.json
└── README.md
```

## 🔧 دستورات تلگرام

- /start - شروع
- /لیست - همه چک‌ها
- /دریافتی - چک‌های دریافتی
- /پرداختی - چک‌های پرداختی
- /امروز - سررسید امروز
- /افزودن - ثبت چک جدید
